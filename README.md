# Проект: Реализация модуля калькулятора на C для Python

## Описание проекта

Тут представлена простая реализация калькулятора с использованием исключений - создан для изучения материала.

## Содержание модуля

Модуль `calculator` предоставляет 4 арифметические функции:

- **`sum(a, b)`** — сложение двух чисел (позиционные аргументы)
- **`sub(a, b)`** — вычитание двух чисел (поддерживает именованные аргументы `a` и `b`)
- **`mult(a, b)`** — умножение двух чисел (позиционные аргументы)
- **`div(a, b)`** — деление двух чисел с проверкой деления на ноль


## Пример использования

```python
import calculator

print(calculator.sum(10, 5))      # 15.0
print(calculator.sub(a=10, b=3))  # 7.0
print(calculator.mult(4, 5))      # 20.0
print(calculator.div(10, 2))      # 5.0
print(calculator.div(10, 0))      # ZeroDivisionError: DO NOT DO DIVISION ON 0!!!
