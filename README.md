# Проект: Реализация модуля print на C для Python

## Описание проекта

Тут представлена простая реализация обёртки над стандартной функцией `printf` из библиотеки C - создан для изучения материала.

## Содержание модуля

Модуль `print` предоставляет 1 функцию:

- **`myprint(str)`** — принимает строку и выводит её через `printf` (позиционные аргументы)

## Реализованные механизмы CPython API

- `PyArg_ParseTuple` — разбор позиционных аргументов (формат `"s"` для строки)
- `printf` — стандартная функция вывода из `stdio.h`
- `PyLong_FromLong` — возврат значения 1 в виде Python-объекта
- `PyMethodDef` — таблица методов модуля
- `PyModuleDef` и `PyInit_print` — инициализация модуля

## Пример использования

```python
import print

result = print.myprint("Hello, World!")
print(f"Return value: {result}")  # Return value: 1
```
