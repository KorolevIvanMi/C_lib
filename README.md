# Проект: Реализация модуля spam на C для Python

## Описание проекта

Тут представлена простая реализация обёртки над системной функцией `system()` с использованием пользовательского исключения - создан для изучения материала.

## Содержание модуля

Модуль `spam` предоставляет:

- **Функция `system(command)`** — выполняет shell-команду, возвращает код возврата
- **Исключение `spam.SpamError`** — пользовательское исключение, выбрасывается при ошибке выполнения команды

## Пример использования

```python
import spam

# Успешное выполнение
result = spam.system("echo Hello")
print(f"Return code: {result}")

# Ошибочное выполнение
try:
    spam.system("invalid_command")
except spam.SpamError as e:
    print(f"Error: {e}")
```
