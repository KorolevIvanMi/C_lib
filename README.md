# Проект: Реализация пользовательского списка на C для Python

## Описание проекта

Данный проект направлен на разработку пользовательской библиотеки для языка Python, написанной на языке C с использованием стандартного CPython API. Основная цель — создать собственную эффективную реализацию структуры данных «список» (аналог встроенного `list`), обеспечив комфортный интерфейс для работы из Python-кода.

## Текущий статус проекта

**Статус:**  **Основная функциональность полностью реализована!** Осталось только провести сравнительное тестирование производительности.

### Что уже сделано:
- Полноценная структура данных на C с динамическим массивом `PyObject*`
- Управление памятью (выделение, освобождение, изменение ёмкости) 
- Модульная архитектура проекта:
  - `list_module.c` — основная реализация типа `List`
  - `core_module.c` — базовые операции управления памятью и структурой
  - `read_module.c` — операции чтения (доступ по индексу, итерация, поиск)
  - `update_module.c` — операции изменения (добавление, вставка, замена)
  - `delete_module.c` — операции удаления (pop, remove, clear)
- Все основные операции:
  - Создание списка (`List()`)
  - Добавление в конец (`append`)
  - Вставка элемента (`insert`)
  - Удаление элемента (`pop`, `clear`)
  - Доступ по индексу (`__getitem__`, `__setitem__`)
  - Проверка длины (`__len__`)
  - Итерация (`__iter__`)
  - Поиск элемента (`index`)
  - Проверка вхождения (`__contains__`)
  - Сложение списков (`__add__`)
  - Умножение списка (`__mul__`)
  - Разворот списка (`reverse`)
  - Сортировка (`sort`)
  - Поддержка срезов (slicing) для `__getitem__` и `__setitem__`
  - Полный набор методов для работы со списком (подробнее через `help(List)`)
- Стабильная работа и отсутствие утечек памяти (проверено через Valgrind)
- Настроенная сборка через Makefile
- **Готовая система установки через `pip`/`uv`/`poetry`**

### Осталось сделать:

## Установка и использование

### Установка через pip (рекомендуемый способ)

Библиотека устанавливается одной командой прямо из GitHub:

```bash
# Установка через pip
pip install git+https://github.com/KorolevIvanMi/C_lib.git

# Установка через uv (быстрее и современнее)
uv pip install git+https://github.com/KorolevIvanMi/C_lib.git

# Установка через poetry
poetry add git+https://github.com/KorolevIvanMi/C_lib.git
```

### Ручная сборка из исходников

Если вы хотите собрать библиотеку вручную:

```bash

cd C_lib

# Установка в виртуальное окружение
```

### 🔧 Доступные команды Makefile


###  Пример использования

```python
from mylist import List

# Создание списка
lst = List([1, 2, 3, 4, 5])

# Добавление элементов
lst.append(6)
lst.insert(2, 99)

# Доступ по индексу
print(lst[0])  # 1
lst[3] = 100

# Удаление
lst.pop()      # удаляет последний

# Итерация
for item in lst:
    print(item)

# Проверка длины
print(len(lst))

# Разворот
lst.reverse()

# Сортировка
lst.sort()

# Срезы
print(lst[1:4])

# Умножение
lst2 = lst * 2

# Сложение
lst3 = lst + lst2

# Поиск
print(lst.find(3))
print(3 in lst)
```

### Справка по методам

Для получения полного списка всех доступных методов выполните:

```python
from mylist import List
help(List)
```
